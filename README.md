# E-Suda Operations Console — demonstration

A running demonstration of the E-Suda staff console (blueprint §2.9), hosted
for client review.

**Everything in it is invented.** The orders, customers, tickets and figures
are generated in the browser; there is no server, no database and no customer
data. Reloading the page resets it.

The behaviour, however, is the product's own: the console refuses what the
real service refuses — a courier holding live work cannot be taken off duty, a
declined identity review needs a reason, a balance cannot be moved without one.

This repository contains only the compiled demonstration. The application
source is private.
